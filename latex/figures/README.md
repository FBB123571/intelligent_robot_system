# 图片与图源

已提供三个可编辑 TikZ 图源：`route_topology.tex`、`system_architecture.tex`、`trail_following.tex`。均为方案示意，不是实测图。

现场照片尚需从原图归档；会话中的图片没有可供直接复制的本地路径。正文预留：

| 文件名 | 内容 | 归档要求 |
|---|---|---|
| `site/corridor.jpg` | 用户提供的灰色挡板通道全景 | 标注方向、拍摄位置；地面胶带不作为识别依据 |
| `humanoid/marker_debug.jpg` | 用户提供的实机屏幕照片，包含标记A框与运行日志 | 原图；窗口数值不当作完整统计 |
| `follow2/robot.jpg` | 用户提供的 TurtleBot2/Kinect 实物照片 | 补记安装姿态、深度来源 |

也可新增转角、RViz `/scan`、地图、路径与终点照片，放入 `site/`、`follow1/`、`follow3/`、`follow4/` 等对应目录，再在本组章节引用。不得将截图里的无关人员、账号或其他个人信息作为报告必要内容；照片注明“本组现场拍摄”或真实来源。
