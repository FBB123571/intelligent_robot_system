# 二维码迷宫路线（TonyPi）

TonyPi 原地抱起方块，靠墙上的三张标记码完成路线：走向 **A** 后左转，走向 **B** 后右转，走向 **C** 后停下并放下方块。直行时保持目标码在画面中央。独立 Python 程序，不依赖网页控制台和 ROS。

**状态**：识别、测距和路线逻辑通过了离线测试（`tests/test_maze_route.py`）；实机已跑通"抱起 → 走向 A → 在 40 cm 处左转"，完整路线尚未实机验收。

## 文件

| 文件 | 作用 |
|---|---|
| `marker_route.py` | 主程序：抱起、识别、对中、转弯、停车、放下，窗口显示和日志 |
| `markers.py` | 三张码的识别与测距（`solvePnP`，边长 14 cm） |
| `robust_camera.py` | 摄像头读取：按 USB ID 打开、掉线自动重连、只返回新帧、占用时让控制台释放 |
| `actions/` | 动作副本，见下 |
| `mkcopies.py` | 在 Pi 上从 `~/TonyPi/ActionGroups` 重新生成 `actions/` |

## 动作

只用队伍指定的基础动作；副本的帧和时长不变，只改手臂：

| 用途 | 副本 | 相对原动作的改动 |
|---|---|---|
| 抱起 | `grab_final_v2.d6a` | 无 |
| 直行一步 | `catch_ball_go.d6a` | 手臂 6/7/8/14/15/16 = `grab_final_v2` 最后一帧 |
| 转弯与对中 | `catch_ball_turn_left/right.d6a` | 同上 |
| 放下 | `put_down.d6a`（官方） | 仅第一帧（下蹲）手臂改为抱紧姿态，避免下蹲时滑落 |

程序自己播放帧：手臂锁定在抱物姿态；若某动作第一帧与当前姿态相差超过 25，就把这一帧拉长到 300 ms 平滑过渡。两次直行之间停 200 ms，路口转弯前后各停 300 ms。

## 运行（在 Pi 上）

```bash
cd ~/TonyPi/maze            # 或本仓库的 humanoid/maze_route
python3 marker_route.py     # 有桌面：窗口里按 S 开始
python3 marker_route.py --dry-run     # 只识别和判断，不走不转（先跑这个）
python3 marker_route.py --headless    # 无显示：3 秒后自动开始
```

启动后先原地 `grab_final_v2`，再走路线，到 C 后 `put_down`（`--no-grab`、`--no-release` 可跳过）。启动时会停掉占用舵机串口的 `tonypi.service` 并关闭厂家上位机，用完需要时手动 `sudo systemctl start tonypi`。

窗口按键：**S** 开始/继续，**P** 本动作后暂停，**Q** 退出，**[ ]** 未运行时调头部俯仰。

日志：`logs/route-<时间>/` 下 `route.log`（事件）、`decisions.csv`（每次判断的距离、方位角、朝向和动作）、`snapshots/`（每次判断的标注图）。无头模式同样记录。

## 决策逻辑

1. 每步前看 3 帧取中位数。目标码方位角超过"单次转角 × 0.6"才转一次修正，否则直行。单次转角运行中实测（实机约 30°），避免大幅转向来回摆。
2. 学习每步的偏航（实机抱物直行每步左偏约 10–15°）；看不到码的盲走阶段按它补偿。
3. 到 A/B 的距离 ≤ `--turn-cm`（40）后，持续转弯直到看到下一张码，再直行；最多转 `--max-corner-turns`（12）次。
4. 到 C ≤ `--stop-cm`（40）停下放下。头部中立时码在约 37 cm 内会移出画面下沿；在目标距离 + `--lost-near-cm`（12）以内丢失且基本居中，视为到达。
5. 连续 `--stall-steps`（20）步距离缩短不到 `--stall-cm`（5）、摄像头 60 s 无画面、路口转满一圈仍找不到下一张码时：有窗口则暂停等 S，无头则停止。摄像头短暂掉线时原地等待。

## 标定事实

- **标记码**不是 OpenCV 自带的 ArUco/AprilTag 字典：9×9 格，外圈 2 格黑边，中间 5×5 数据，黑色正方形 14 cm。模板见 `markers.py` 的 `TEMPLATES`，三者在任意旋转下至少相差 4 格，识别允许错 1 格。
- **头部**全程中立：PWM 舵机 1 = 1500（俯仰），2 = 1482（`servo_config.yaml` 居中值），开局设一次。
- **距离**是摄像头到码中心的直线距离；码中心比摄像头低约 13 cm，水平 40 cm 时读数约 42 cm。
- **相机内参**读取 Pi 上 `~/TonyPi/Functions/CameraCalibration/calibration_param.npz`。
- 离线测试中 30–60 cm 测距误差约 1–2 cm、朝向误差 ±2°；实机 194 cm 处已能识别。

## 已知问题

- 抱物直行（`catch_ball_go` + 抱物手臂）每步只前进约 3.4 cm 且明显左偏，全程预计 5–7 分钟，一半以上动作在纠偏。调直步态是最有效的改进。
- USB 摄像头会在转身等舵机大负载时掉线数秒，可能是供电跌落；建议固定线缆、检查电量。
- C 离 B 转弯点约 2.2–2.6 m，可能超出识别距离；若右转后转满一圈仍看不到 C，可放大打印或增加保底策略。
